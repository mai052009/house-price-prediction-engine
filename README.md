# house-price-prediction-engine
An automated valuation model analyzing structural and geographic data to predict housing price using Python and scikit-learn regression pipeline
# Real Estate Valuation Engine: Predictive Modeling for Housing Markets

## 🏢 Business Overview
In competitive real estate markets, real estate agencies need a smart, data-driven way to calculate property values accurately. Setting prices based on guesswork leads to homes sitting on the market too long, lost money for sellers, and confused buyers. 

This project uses a data analytics framework designed to help real estate teams, buyers, and sellers. By identifying the exact features that drive home prices (like size and location), this model helps establish reliable property values.

### 🎯 Main Goal
* Figure out exactly how much a home's size, age, and distance from the city change its final sale price.
* Build a machine learning model to predict what a house should sell for based on those features.

---

## 🗃️ The Dataset
Our model is trained on a dataset tracking **1,500 historical home sales**. The dataset includes the following details for every home:

* **Square_Footage:** Total interior living space (sq. ft.).
* **Bedrooms:** Number of bedrooms (ranging from 1 to 5).
* **House_Age_Years:** How old the house is since it was built.
* **Distance_To_City_Miles:** How many miles the house is from the city center.
* **Sale_Price (Target):** The final price the house actually sold for ($USD).

---

## 🔬 Key Insights Found
* **Market Variety:** The homes studied range from compact urban properties ($851 \text{ sq. ft.}$) all the way up to large suburban estates ($4,926 \text{ sq. ft.}$).
* **Price Range:** Home prices in this market start at an affordable $\$80,000$ and reach up to $\$392,102$.
* **Location Matters:** Location and property age show strong patterns—homes get notably cheaper the further away they are from the city center core.
